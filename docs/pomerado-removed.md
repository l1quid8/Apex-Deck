# Pomerado removed

Removed from this Mac on 2026-11-01. No minted website tools were left, the
idle servers were still started by Deck, Claude Code and Codex, and shared
browser tabs now cover bot web work.

Pomerado turned a website into a repeatable MCP tool that ran with no model
calls. To bring that back, install it again and add it as an ordinary MCP
server. Deck still passes saved keys to MCP servers through `${NAME}` in their
config, and any MCP tool with a risky name still shows an approval card.

The old wiring is in git history at `docs/pomerado-wiring.md`.
