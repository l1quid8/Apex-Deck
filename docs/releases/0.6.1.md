# Apex Deck 0.6.1

ApexAgent message actions now sit beneath message bubbles, matching regular threads. This release includes the latest changes from main through `71756cd`.

## Changes

- Reply, Copy, Pin, Retry, Revert, expand/collapse and timestamps in ApexAgent, with emoji reactions retained and Fork omitted.
- Retry requests another answer in the original assistant conversation. Revert restores your message to the composer; it preserves history and files and guards attachment routing.
- Pins persist on this device. Action controls remain outside the message body and composer.
- Removed the explanatory text beneath “Pause project watching.”
- Includes intervening fixes for bot image delivery, attachment thumbnails and keeping the latest message visible after delayed image loading.

## Distribution

Apple Silicon Mac DMG, Linux x86_64 and arm64 daemon binaries, and SHA256SUMS. The Mac app is Developer ID signed but not notarized. This release does not update TestFlight or deploy any service to the VPS. TestFlight 1.1 (5) remains the previous phone build.

## Verification

- 1,153 frontend tests passed; TypeScript and production UI build passed in an isolated release checkout.
- Main commit `71756cd` passed all five CI jobs: macOS and both Linux test jobs, and both Linux build jobs.
- The preceding installed Mac build passed ten native action/placement checks, as recorded during implementation. Those checks precede this versioned package.
