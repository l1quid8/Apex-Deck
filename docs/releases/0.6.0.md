# Apex Deck 0.6.0

ApexAgent now has separate Chat, Tasks and Notifications views. Expanding it fills a dedicated workspace pane; the floating avatar remains available and either collapse control restores the workspace.

## Changes

- Durable personal assistant conversations, approvals, background tasks, schedules, memory and action rules introduced since 0.5.1.
- Result-first task details and short links in chat; actionable attention items live in Notifications.
- Quoted message replies, host-persisted emoji reactions and a composer + menu for supported attachments, tools, commands and mentions.
- Project Sources sheet with chat/file selection, save readback and reachable mobile exit controls.
- Task conversation Close, Reopen, Rename and Delete controls; deleting a settled worker conversation preserves its task result.
- Delivery receipts and retry reconciliation, bounded source context, and brief-only worker handoffs.
- Improved Mac/iPhone layouts and separate assistant/project-watching pause controls.

## Distribution and limits

The full desktop release includes an Apple Silicon Mac DMG, Linux x86_64 and arm64 daemon binaries, and SHA256SUMS. iPhone TestFlight **1.1 (5)** was uploaded on October 11, 2026 and verified available with an Install button. It includes Chat, Tasks, Notifications, quoted replies, emoji reaction controls, and the composer + menu, built from release commit `f2cc9fe`. Durable reactions require a compatible host service; the VPS was not changed.

Updated host services are required for new reaction commands. This release does not deploy to the VPS. Phone folder picking and thread-only composer commands remain unavailable. APNs, Google OAuth, GitHub credentials and Mac-folder authorization need individual configuration. Browser fixture layout checks and automated tests do not establish real-device coverage of every assistant feature. Live expanded-pane/tab/collapse checks remain pending. Check the downloaded Mac app's signing/notarization status before distribution; notarization is not part of this release process.

## Rollback

Reinstall the previous Mac build or select an earlier GitHub daemon asset. Back up assistant data before downgrading; this release adds persisted conversation metadata and reactions. Restarting a daemon interrupts in-progress replies.
