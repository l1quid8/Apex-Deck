# Apex Deck 0.6.2

This release packages the application changes from `main` through `9ec02fa`. The release metadata and README refresh are included on current `main`.

## Changes

- ApexAgent messages in Threads now include Read aloud, using the shared speech control.
- The ApexAgent message-row chevron collapses its action buttons while leaving message text visible.
- Refined the native title bar and pane layout: tighter pane spacing, smaller title bar controls, corrected sidebar-toggle placement, and a draggable inset title bar.
- Checkout write coordination now applies only to ApexAgent task threads. Ordinary chat threads remain ungated so independent chat turns can run concurrently.

## Distribution

Apple Silicon Mac DMG, Linux x86_64 and arm64 daemon binaries, and SHA256SUMS. The Mac app is Developer ID signed and not notarized. This release does not update TestFlight or deploy any service to the VPS.

Back up assistant data before downgrading. Restarting a local daemon interrupts active replies.
