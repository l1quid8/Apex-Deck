## Updated behavior since the published 0.9.9 release

- Shared desktop, phone and CLI turn progress, including clearing progress after
  successful compaction, and generated daemon command schemas.
- Apex Code Mode for eligible Claude Code and Codex workers, with Auto/Off
  controls and turn-scoped authority. Persistent eligible workers preserve
  room context across clean turns and rotate authority between turns.
- Shared desktop/phone retry, revert, history confirmation and pin behavior.
- Protected document read coalescing and write admission, deferred closed-thread
  hydration, normalized workspace saves, and early default-chat acknowledgement.
- Updated Windows phone authority grants, platform labels and shortcut display.
- macOS Computer Use lifecycle and lock revocation; signing/notarization tooling.
