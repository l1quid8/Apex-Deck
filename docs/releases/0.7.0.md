# Apex Deck 0.7.0

This release packages the application changes from `main` through the Muse Code bot merge (`8c11e08`). The headline is the new Muse Code bot; it also picks up everything since 0.6.2 (right panel tabs, files tab, worktrees tab, phone terminal attach, Claude plugin menu).

## Changes

- New bot type: **Muse Code (Meta)**. It starts the real `muse` program on your Mac and drives it over MSP, so it bills to your Muse Code subscription (Everyday or higher), never pay-per-use. Streaming replies, tool activity, approval cards, stop, and a model menu (Wonder 1.0, Spark 1.3, Spark 1.2) with per-model thinking levels.
- Billing safety: `META_API_KEY` is stripped from the environment before Muse starts, since a key would override the subscription sign-in. Contributor mode and Muse session logging are off for Deck-started runs.
- Honest permissions: Muse writes files without asking and lets its own judge clear harmless commands, so "ask first" is read-only for Muse (as for Grok). Edits keeps the sandbox with escalations to you; full access drops it, like the other bots.
- Cost notice: the add-bot form warns that each message sends about 24k tokens of Muse's built-in instructions, so an Everyday plan's 5-hour allowance can run out after a few busy chats. The bot card shows 5-hour and weekly usage after the first reply.
- Right panel tabs (Dashboard, Tasks, Browser, Files, Details), project file search/preview/tree, Git worktrees tab, phone terminal attach, and the Claude bot plugin menu.

## Distribution

Apple Silicon Mac DMG, Linux x86_64 and arm64 daemon binaries, and SHA256SUMS. The Mac app is Developer ID signed and not notarized. This release does not update TestFlight or deploy any service to the VPS.

Back up assistant data before downgrading. Restarting a local daemon interrupts active replies.
