# Apex Deck 0.9.0

This release packages everything on `main` since 0.7.0. The 0.8.x numbers were used only for local test builds and were never published. The headline is **Your team**: named assistants that coordinate your agents across projects, now with a simpler Chat and Work layout that follows every Appearance theme.

## Changes

- **Your team.** Named assistants replace the floating ApexAgent widget and open in the main window. Each teammate has its own conversation, memory, projects and avatar (a pixel pattern, or an image generated with a configured image model). A teammate hands coding work to your reusable agents in its assigned projects and brings the results back.
- **Chat and Work.** A teammate's page has two tabs. Chat always keeps its message box; finished results arrive as cards with one **Mark reviewed** or **Accept** step. Work lists what needs you, what is running, the teammate's projects, and what finished.
- **One status everywhere.** The sidebar row, the header and Work count the same tasks. A Ready teammate stays quiet; only Needs you, Failed, Working, Paused and Offline get words and colour.
- **Simpler settings.** Settings is one short column: General, Model, Projects & access, Memory, Tools & rules, with a save bar that counts your changes. Turning on a project whose folder is not yet allowed asks for that folder first.
- **Add a teammate** is one short form: name and avatar, model, access, an optional first brief (placed in the new teammate's message box, never sent for you), and More options for machine and folder. A new teammate's empty chat shows the same glyph rain as a new thread.
- **Protected assistant data.** Conversations, tasks and memory for named assistants live in Deck's protected data store rather than plain files.
- **Voice calls.** A microphone beside Send starts a call with a bot in the thread, with per-bot voices and mute. Local speech runs on the Mac after an optional download.
- **Themes.** A new Clay theme (warm paper, serif replies, light and dark), and every assistant screen now follows the chosen theme: Classic, the glass skins (Smoked, Tide, Dusk, Rose, Frost, Liquid) and Clay.
- **Threads and panes.** Pop-out panes, a full-screen side panel and file editor, runnable code blocks, a collapsed changed-files strip, unlimited model-to-model rounds, a per-bot Speed setting, configurable bot chip styles, and tools (files, shell, web, MCP) for Ollama and other API bots.
- **Phone.** Message actions, paste fixes, a speed setting in the bot sheet, and pairing driven by the daemon.

## Distribution

Apple Silicon Mac DMG, Linux x86_64 and arm64 daemon binaries, and SHA256SUMS. The Mac app is Developer ID signed and not notarized. This release does not update TestFlight or deploy any service to the VPS.

Back up assistant data before downgrading. Restarting a local daemon interrupts active replies.
