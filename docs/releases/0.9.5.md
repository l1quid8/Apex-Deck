# Apex Deck 0.9.5

- **Goals and loops.** Start bounded goals and recurring work from the desktop or phone composer, with progress, limits, pause and stop controls.
- **More reliable runner startup and recovery.** Runner storage failures stay isolated, and unfinished work pauses after recovery instead of replaying automatically.
- **Faster assistant polling.** Polling avoids repeatedly opening protected runner storage, and deleted task patches stay out of assistant updates.
- **VPS automatic updates.** The managed updater builds newer published stable tags, preserves the deployed Linux Allow behavior, tests Allow, Allow always and new-thread creation, waits for idle work, and retains a rollback executable. Active goal/loop workers also defer updates.

This release includes a Developer ID signed macOS Apple Silicon installer and its automatic-update manifest. macOS notarization is not configured. No Windows installer is included.

Validation: TypeScript and the focused updater policy tests pass. The macOS daemon CI job passed. CI still reports Linux adapter isolation test failures and a Windows `gateway_sandbox.rs` compilation failure; this is not an all-platform green CI release. The managed VPS updater independently requires its focused Linux compatibility and maintenance checks to pass before installation.
