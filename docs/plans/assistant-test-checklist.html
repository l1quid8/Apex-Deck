Assistant test checklist

Build 486f5f7 on Mac, VPS and iPhone · conversation cleared 2026-10-10 · ·

Do each step, tick it, and tell Jigga the step number. Jigga checks the VPS record after each one for duplicates. If something looks wrong, screenshot it and stop there.

A · Basics on a clean conversation ~5 min

A1. Empty conversationiPhone + Mac
Open "Your assistant" on the phone and press ⌘K on the Mac.
Expect: no old messages or task cards on either.
A2. Plain questioniPhone
Send What time is it where I am?
Expect: a quick reply, no task card, and the same reply shows on the Mac.
A3. Read command runs without askingiPhone
Send How much disk space is free on the server?
Expect: one task card, runs df with no approval, shows the result once.

B · Pause, Resume and Stop ~5 min

B1. PauseMac
⋯ → Pause assistant. Then from the iPhone send Delete ~/apex-assistant-slice/test.txt and press Approve.
Expect: header says "Paused", it asks for approval (delete is a change), and after Approve it says it will start when you resume. Nothing runs yet.
B2. Still answers while pausediPhone
Send What's 2 + 2?
Expect: it answers within a few seconds.
B3. ResumeMac
⋯ → Resume assistant.
Expect: the delete runs exactly once and the card shows Done.
B4. Stop a long commandiPhone
Send Run sleep 60 on the server, approve it, then press Stop task while it's running.
Expect: card turns Cancelled straight away and says the command was stopped. Nothing re-runs.

C · Waiting tasks and schedules ~10 min, mostly waiting

C1. "Check again later"iPhone
Send In 5 minutes, check how long the server has been up, then close both apps.
Expect: after 5 minutes, reopen: one result, posted around the 5-minute mark.
C2. "After that finishes"iPhone
Send Run sleep 20, and after it finishes run uptime
Expect: uptime starts only after sleep ends; each runs once.
C3. Schedule, then cancel itiPhone
Send Every day at 9am, tell me the free disk space, confirm it, then ⋯ → Scheduled → Cancel schedule.
Expect: it shows under Scheduled after you confirm, and disappears after cancelling.

D · Memory through chat ~3 min

D1. RememberiPhone
Send Remember that my favourite editor is Zed
Expect: ⋯ → Memory shows it once.
D2. Correct itiPhone
Send Actually my favourite editor is VS Code, then ask What's my favourite editor?
Expect: answers VS Code; Memory shows only the new one.
D3. Forget itiPhone
Send Forget my favourite editor
Expect: Memory is empty.

E · Rules and spending ~5 min

E1. Standing ruleMac
⋯ → Rules → add Always ask before running any command. Then send Run uptime.
Expect: it asks first even though uptime only reads. Remove the rule afterwards.
E2. Spending limitMac
⋯ → Settings → set "Daily spend limit" to 0.01, then send any question.
Expect: it asks before spending more. Set the limit back afterwards.

F · Helpers, privacy and Take over ~5 min

F1. HelpersiPhone
Send Use helpers: compare Zed and VS Code for speed, plugins and price
Expect: one combined answer, not three separate ones.
F2. Local-only modeMac
⋯ → Settings → tick "Local only", send a question, then turn it off.
Expect: it refuses to send the question to a cloud model and says why.
F3. Browser Take overiPhone
Send Open example.com in your browser, then tap Take over and tap a link.
Expect: you see the page and your tap works.

G · Notices runs alongside the rest

G1. No repeatsiPhone
Send Every minute, check if test.txt exists in your folder and stop when it does. Tell Jigga, who creates the file.
Expect: exactly one "Condition met" notice.
G2. Quiet hoursMac
⋯ → Settings → set quiet hours to cover right now, then repeat G1.
Expect: the notice waits until quiet hours end (or shows in-app only). Reset quiet hours afterwards.
