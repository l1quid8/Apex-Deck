Terminal quick switcher

v2 of the iPhone Code tab terminal, built on the design review's own parts (same colours, type sizes, frame, rows and sheet) so it can sit next to dark-code.png and dark-terminal-full.png.

How you switch

  • Tap a name in the row under the title. One dot per terminal: green pulsing is running, amber is asking you something, red means the last command failed, an empty ring is idle, grey has finished.
  • Swipe the output left or right for the next or previous one. The next name shows at the edge while you drag.
  • Tap the title line for every terminal on every paired machine, with search over names and recent output.
  • Hold the Code tab from anywhere to open that same list. An amber dot on the tab means a terminal is waiting for an answer.
  • Hold a terminal in the list for Rename, Copy last output and End.

What changed from v1

  • Same parts as the design review: phone frame, 29 px title, status pill, output box, key row and command field.
  • The Code tab keeps every row from dark-code.png. Browser and Latest build stay in place, marked Later, because nothing feeds them yet.
  • Answer buttons for a terminal asking a yes/no question (state 5), and Run again for a finished one (state 6).
  • The list only claims what the Mac can know: terminals opened in Apex Deck. Terminal.app and iTerm windows aren't listed.

Needs the Mac service first

  • A list of open terminals with name, folder, who started it and state (Luna sized this as medium).
  • A short buffer of recent output per terminal, so the phone can join partway through.
  • State 8 means letting a phone below Full access read terminal output. Output can contain secrets, so that's your call, not a quick switch.
