# Assistant live turn — same surface as Threads

```text
Conversation messages

[animated avatar] Alfred
[•••] Alfred is working…   0:12  ⌄  [Stop]
      (tap to expand reply status)

──────────────────────────────────────────
[ + ] [ Message Alfred…    TL;DR     mic ]
```

Reuse PhoneWorkingTurn in both screens. Stop stays beside the activity, inside the transcript. No separate status row above the composer. Queued messages remain visible. Offline status stops animation and disables Stop. Personal events supply pending time and state, not streamed tool steps; do not invent progress.
