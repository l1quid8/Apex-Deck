Jigga's v2. Same data and menus as today, with the boxes taken out. Tap a project to fold it, hold any row for its menu, try + for New thread.

  • No cards, no borders. Rows are plain text on the page. Pressing one lights it up, so they still feel tappable without looking like big buttons.
  • One dot, one meaning. A dot in the left margin: amber waiting on you, mint working, cyan unread. No dot means nothing to do.
  • Every title starts on the same line. Labels, threads and projects share one left edge; the dots hang outside it.
  • The second line is a sentence, such as "Gronk is working in relay". A purple globe marks a server project.
  • Projects are a name, a count and a chevron. + appears only on an open project. Pinned projects sort first and show a small pin.
  • A machine that drops says so on its own label, with Retry. Nothing else on the page changes colour.
  • Gone from v1: the coloured rails, count bubbles, the boxed offline card, the "hold for menu" hint and the per-project New thread line.
