  • Thread menu: "Jigga details", "Null details" and "Bots…" collapse into one Bots row (avatars + count). The path appears once, in the card, in the normal font, with the machine's connection dot. Copy folder path drops its repeated path. Rows are grouped (bots / thread actions / Archive) and 48 px tall instead of ~78 px.
  • Bots sheet: two sections, In this thread and Add a bot. Rows are 56 px with avatar, name, @handle and (for members) model. Round −/+ buttons are 44 px tap targets. Tapping the rest of a member row opens the existing bot details sheet (model, reasoning, context, plan).
  • Feedback: spinner on the tapped row, other buttons wait; pending additions stay in Add a bot until success; success moves the bot; removal can be reversed with +, without an Undo toast; failure stays on that row in red with a retry. A bot that is mid-reply can't be removed until it is stopped (the existing Stop in its details).
  • Bot row under the title: solid background, a clean bottom edge and a soft shadow so chat text no longer shows through; the stray small dashes under the pills are gone.
  • No Full access: the Bots row still opens; buttons are greyed with one line on how to change access, instead of a notice that blocks opening it.

Review decisions

  • Allow removing the last bot. Show “No bots yet” and disable Send until a bot is added.
  • No Undo: the + button adds a removed bot back.
  • Sheet content scrolls independently; title and 44 × 44 close target stay reachable.
  • Pending additions remain in Add a bot until the server confirms success.
