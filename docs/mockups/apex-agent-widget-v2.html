New in v2
  • Each project keeps its own chat, sources and blockers; the avatar counts across all of them
  • Dropping a file says "Adding…", then "Added" only once it's saved; duplicates and bad drops are refused
  • ⌘K opens it (⌘J stays Deck's "next thing that needs you"); full keyboard use
  • Moves beside a docked browser instead of vanishing under it
  • Status line no longer cut off; the glow stays inside the window
  • Review fixes: a drop stays with the project it was dropped on even if you switch mid-save; resolving a blocker also removes its bubble; the project chip no longer covers the status
