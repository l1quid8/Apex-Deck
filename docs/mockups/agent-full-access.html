Confirmation dialog

Confirm Full access for Null on VPS?

Full access allows this agent to execute commands and code written by other agents within its allowed folders on this machine. This applies across threads and worktrees and survives restarts. It does not grant additional folders. Restricted access restores its normal checks. You can revoke this approval in agent settings.

After confirmation

Full access confirmed on this machine across this agent’s allowed folders and threads. This approval applies while the agent uses Full access.

Revocation stops active Full copies of this agent on this machine. This control remains available while using restricted access.
