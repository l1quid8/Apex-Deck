Terminal quick switcher

Jigga's v1, from the Terminal and Code shots in the iOS design review. Every terminal on every paired machine, one tap or one swipe apart.

  • Three ways to switch. Tap a name in the strip under the title. Swipe the output left or right for the next one. Tap the title line (apex-deck · dev server ▾) for every terminal on every machine.
  • Hold the Code tab from anywhere in the app to open the same switcher. Tapping Code while you're on a terminal jumps back to the last one you used.
  • One dot, one meaning. Mint pulsing: a command is running. Amber: it's asking for input (a y/n prompt, a password). Red: the last command failed. No dot: idle at the prompt.
  • Your Mac's terminals and phone shells sit together. Shells started from the phone say "this phone". + next to the title starts a new shell in the current project.
  • Hold any terminal in the switcher for Rename, Copy last output and End.
  • The Code tab's Terminal row shows the count and what's running, plus the three most recent terminals so you can jump straight in.

Needs new daemon work

  • Listing the Mac's terminals and replaying their recent output. The daemon can't do either today, so v1 of the plan only had phone-owned shells. This switcher needs a terminal list and a scrollback buffer per terminal.
  • Read-only following (state 8, as in the design review). Terminal output is Full-access only today, so below Full the phone would see nothing until that changes.
  • The amber "asking for input" dot is a guess from the last output line (ends in [y/N], password:…). Cheap, but it can be wrong.

Left out

  • Bots' own commands. They run as one-off tool calls, not terminals, so there's nothing to attach to. They stay in the thread.
  • The Browser row and Latest build card from the Code shot (no feature behind them yet, see the plan).
