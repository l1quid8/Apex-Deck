Apex CLI — approval card (mockup v1)

Design only, nothing is built. Each screen is a 100-column terminal using the CLI's colours. Left is today's 0.9.12 request list; right is the proposed card. Agent names, folders and commands are sample text. Pick a case:

    Keys on the card

    AApprove. The footer turns into "Approve? Y yes · N back" so one stray key can't run anything.
    YConfirm the approve (only while the confirm line is showing).
    RReject straight away. No confirm, because rejecting is always safe.
    DShow or hide the full command or diff, if it's longer than the card shows.
    TabNext request, when more than one agent is waiting.
    EscHide the card. The agent keeps waiting; F2 brings it back.
    EnterDoes nothing on the card. No default choice, so a stray Enter can't approve or reject.
