Jump to the newest message

  • Shows when you're more than about a screen from the end, hides when you're there. It sits on the chat, not on the chat box, so it never covers what you're typing.
  • The thread already tracks whether you're at the end (to decide whether to follow new replies). The button reads that, so it adds no new scroll logic.
  • The button is a safety net. A thread that opens at the top on its own is a bug, and I'll fix that separately.

Worktrees pane

  • Opens from a button, not a swipe. Swiping left and right already moves between your open threads, so a swipe from the right edge can't also open this. Close it with ×, by tapping the dimmed thread, or by swiping the pane to the right.
  • Only in threads that have a project folder. Plain chats don't show the icon.
  • Same list and actions as the Mac's Worktrees tab, read from the same place on the Mac. Two phone changes: plain rows, one state dot each, no boxes; and actions live in a bottom sheet instead of a ⋯ menu.
  • Dots: green pulsing = working, green = folding back or main, amber = needs you, hollow = folder missing.
  • Agent copies you can't remove by hand while they're working. A copy that needs you gets a Discard copy action.
  • Left out on purpose: “Open folder” (Finder is on the Mac, not the phone).
  • Phones without Full access see the list but no New, Mount, Prune or Remove, same as the agent editor rule.
