  1. Not connected yet — hollow dot, the sidebar's words. "Connect" starts it now.
  2. Connecting / catching up — amber dot. No button; it's already trying.
  3. Can't reach — grey dot, red words (same as the project hover card), then the raw reason in small mono so you can fix it. Retry, Edit…, Remove.
  4. Old helper — connected, but the version or build doesn't match this app. Same words as the banner.
  5. Remove refused — the error sits on that host's own line, not at the bottom of the page.
  6. This Mac — no buttons while connected (it can't be edited or removed). Retry appears only if it isn't connected.
  7. Empty — when This Mac is the only host, this quiet line sits under it.

Add a server

The machine needs apex-daemon running (see docs/daemon-ubuntu.md) and an SSH key this Mac already uses for it. Run ssh vps once in Terminal first so its host key is known; Deck never asks for a password.

ssh me@build.example.com apex-daemon --stdio --attach
Connected. apex-daemon 0.7.0 is running there.
Remove Apex-Terminal?

Deck stops connecting to it. Nothing on that machine is deleted, and you can add it again later.
